# Network Reconnaissance & Traffic Analysis Lab

## Project Overview

This project demonstrates basic network reconnaissance and traffic analysis in a controlled lab environment using Kali Linux, Nmap, Wireshark, and a Windows test machine.

## Lab Environment

- Kali Linux VM
- Windows Laptop 1
- VirtualBox Bridged Adapter
- Nmap
- Wireshark
- Python HTTP Server

## Network Details

Kali Linux:
- IP Address: `192.168.100.108`
- Interface: `eth0`

Windows Laptop 1:
- IP Address: `192.168.100.66`

Network:
- `192.168.100.0/24`

## Host Discovery

Command:

```bash
nmap -sn 192.168.100.0/24
```

The scan discovered active hosts on the local network.

## Basic Port Scan

Command:

```bash
nmap 192.168.100.66
```

The Windows host was reachable, but the default scanned TCP ports were reported as filtered because of firewall filtering.

## Open Port 8080 Test

A temporary Python HTTP server was started on the Windows machine:

```powershell
python -m http.server 8080
```

Kali Linux scanned port 8080 using:

```bash
nmap -p 8080 192.168.100.66
```

Result:

```text
8080/tcp open
```

This confirmed that TCP port 8080 was reachable and a service was listening.

## Service Version Detection

Command:

```bash
nmap -sV -p 8080 192.168.100.66
```

Nmap identified the service as:

```text
SimpleHTTPServer 0.6 (Python 3.14.8)
```

## Wireshark Traffic Analysis

Wireshark was run on Kali Linux using interface:

```text
eth0
```

Display filter:

```text
tcp.port == 8080
```

The capture showed:

- TCP SYN
- SYN-ACK
- ACK
- HTTP GET traffic
- TCP connection closing/reset packets

This confirmed that the Nmap scan generated real TCP and HTTP traffic between Kali Linux and the Windows lab machine.

## Key Concepts Learned

- Host discovery
- Network range identification
- Basic TCP port scanning
- Difference between open and filtered ports
- Service/version detection
- TCP handshake analysis
- HTTP traffic inspection
- Wireshark display filtering
- Relationship between Nmap scans and captured network traffic

## Final Result

The lab successfully demonstrated how Nmap can discover hosts, scan ports, identify services, and how Wireshark can verify the traffic generated by those scans.

## Disclaimer

This project was performed only in a controlled and authorized lab environment for educational purposes.
